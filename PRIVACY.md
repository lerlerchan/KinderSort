# KinderSort Privacy Statement

**Effective date: November 17, 2026**

KinderSort is an offline desktop application for organizing student photos. This statement explains what happens when you use the KinderSort website and desktop application.

## The website

The website is a static information and download site. Its source currently includes no analytics, advertising, tracking pixels, accounts, or contact forms. It does not upload or process student photos.

The website saves your language choice (English or Chinese) in your browser's local storage so it can remember that preference. This preference stays in your browser and is not sent to KinderSort by the website.

The website links to GitHub for project information and downloads. GitHub and any website hosting provider may process technical information such as IP address, browser details, and request time when you visit their services. Their own privacy policies apply to that processing.

## The desktop application

Photo sorting happens on the computer where KinderSort is running. The application does not send reference photos, event photos, face encodings, filenames, or sorting results to KinderSort or a cloud service. It does not require an internet connection to sort photos.

During a sorting session, the application processes selected images and holds face encodings in memory to compare faces. It does not save those encodings as a separate file. The application copies photos into the output folder; it does not move or delete the original photos.

The application writes a log named `kindersort_log.txt` in the selected output folder. The log may contain local file and folder paths, image filenames, sorting activity, and reference-photo error details. The output folder also contains copies of matched and unmatched photos. These files remain under your control; protect them and remove them when they are no longer needed, subject to your school's retention rules.

## Student photos and your responsibilities

Student photographs and information derived from faces can be sensitive personal information, especially when they relate to children. Use KinderSort only with the authority and permissions required by your school and applicable law. Follow your school's rules for access, storage, retention, and sharing; restrict access to the input and output folders; and manually review matches before sharing photos.

## Changes to this statement

This statement may be updated when the website or application changes. The effective date above indicates when this version was last updated.
