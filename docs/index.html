GOOD TO KNOW

A few quick
questions.

Answers to the things teachers usually want to know before getting started.

Do I need an internet connection?+

No. Photo sorting runs on your Windows computer without uploading images to a cloud service. You only need internet to visit this website or download the application.

What happens to my original photos?+

KinderSort copies photos into output folders; it does not move or delete the original input photos. Start with a separate output folder and keep backups of important school files.

Can it organise group photos?+

Yes. A group photo may be copied to more than one student's folder if multiple students are matched. Always review results for accuracy.

What if a face isn't recognised?+

Photos without a student match go to _unmatched. Processing errors may also preserve readable copies there; check the summary and log to tell the difference.
